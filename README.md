# Predictive-Analytics
This project applies predictive analytics to three problems using a synthetic dataset:

Stock Price Prediction: LSTM model for TECHCORP
Sales Forecasting: Holt-Winters model for North Store
Waiter Tips Prediction: Linear Regression, Ridge, and Random Forest

The project also includes a saved waiter-tip prediction pipeline for predicting new observations.

Files
Dataset – Synthetic project data
Notebook – Complete analysis and modelling
tips_pipeline.joblib – Saved prediction pipeline
Outputs – Graphs and results

Tools: Python, Pandas, Scikit-learn, TensorFlow, Statsmodels, Matplotlib, and Joblib.
